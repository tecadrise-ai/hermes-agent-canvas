Gateway Connection

            

              Same as Hermes Desktop → Settings → Gateway → Remote connection: attach Canvas to an
              already-running Hermes dashboard/backend with a base URL and session token. The
              backend can be on 127.0.0.1 or any remote host. Canvas does not start it.
            

          

          
        


        

          

            
Applies to

            

            

          


          

            
            
          


          

            

              
Remote URL

              

                Base URL of the Hermes dashboard backend (e.g. http://127.0.0.1:9119 or
                http://100.x.y.z:9119). Path prefixes ok, e.g. /hermes.
              

            

            
          


          


          

            

              
Authentication

              

            

            

              
              OAuth gateway
            

            

              Browser OAuth cookies stay on the gateway origin. Prefer a session token for Canvas,
              or paste one after signing in on the gateway UI.
            

          


          

            

              
Session token

              

                Dashboard session token for REST and WebSocket. Leave blank to keep the saved token.
